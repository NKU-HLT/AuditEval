# Towards Automatic Evaluation and High-Quality Pseudo-Parallel Dataset Construction for Audio Editing: A Human-in-the-Loop Method
[ArXiv Paper](https://arxiv.org/pdf/2508.11966) | [Dataset](none) | [Models](https://modelscope.cn/models/YuhangJia/AuditEval/summary) |

## 🧩 Abstract

Audio editing aims to manipulate audio content according to textual descriptions, supporting operations such as adding, removing, or replacing sound events. While recent models have made rapid progress, the field still lacks reliable benchmark datasets and effective evaluation metrics, making it difficult to assess editing quality and guide further development.

In this project, we introduce an expert-informed evaluation framework for audio editing:

1. **AuditScore**: the first comprehensive dataset for subjective audio editing evaluation, containing over 6,300 edited samples generated by 7 representative audio editing frameworks under 23 system configurations. Each sample is annotated by professional raters along three core dimensions: **Quality**, **Relevance**, and **Faithfulness**.
2. **AuditEval**: a family of automatic MOS-style evaluators tailored for audio editing, including both SSL-based and LLM-based variants, designed to approximate human judgment while significantly reducing evaluation cost.

Together, AuditScore and AuditEval provide a unified benchmark and evaluation toolkit for analyzing, comparing, and improving audio editing systems.

## 🛠️ Overview

**Subjective Audio Editing Evaluation Dataset Construction**  
We construct AuditScore, the first large-scale benchmark dedicated to subjective evaluation of audio editing. The dataset covers 7+ representative audio editing methods and 23+ system variants, with each edited sample rated by professional annotators on three essential aspects: 
- **Quality**: Assesses the overall semantic correctness and acoustic integrity of the edited audio:
(1) About the Same / Even Better, (2) Slightly Worse, (3) Noticeably Worse, (4) Much Worse, (5) Severely Degraded.
- **Relevance**: Measures how well the edited audio semantically matches the editing instruction and target description:
(1) Excellent Match, (2) Good Match, (3) Partial Match, (4) Poor Match, (5) Mismatch.
- **Faithfulness**: Evaluates the preservation of unedited content from the original audio in terms of rhythm, timing, loudness, and overall style:
(1) Perfectly Faithful, (2) Mostly Faithful, (3) Partially Faithful, (4) Minimally Faithful, (5) Not Faithful.


**Automatic MOS Prediction**  
Based on AuditScore, we develop **AuditEval**, an automatic evaluation framework for audio editing. AuditEval is trained to predict human MOS-style scores and serves as a practical alternative to costly and time-consuming subjective evaluation, while maintaining strong alignment with human judgments.

## 🚀 Using AuditEval for Automatic Evaluation

This section describes how to use **AuditEval** for automatic MOS-style evaluation of audio editing results. We provide two variants, **AuditEval-SSL** and **AuditEval-LLM**, which differ in their model backbones and evaluation characteristics.
### 🔹 AuditEval-LLM (Speech-Language-Model based MOS Predictor)

1. **Install Required Dependencies**  
   Download the AuditEval-LLM model (post-trained on Qwen2.5-Omni), and install the required dependencies. Alternatively, you may install the latest **[ms-swift](https://github.com/modelscope/ms-swift)** framework:
    ```bash
    pip3 install -r requirements_llm.txt
    pip3 install -U transformers torchaudio torch torchvision qwen_omni_utils xformers openai-whisper
    ```
2. **Run Single-Sample Evaluation**  
   In `AuditEval-llm/infer_once.py`, specify the required input fields (e.g., audio paths and corresponding text descriptions), and then run:
   ```bash
   bash AuditEval-llm/infer_once.sh
   ```

2. **Run Batch Evaluation**  
   Prepare the evaluation data following the format defined in `AuditEval-llm/infer_batch.jsonl`. Then, specify the input file and output directory in `AuditEval-llm/infer_batch.sh`, and execute:
   ```bash
   bash AuditEval-llm/infer_batch.sh
   ```
   AuditEval-LLM is designed to provide stronger semantic reasoning, making it suitable for evaluating complex audio editing scenarios where understanding editing intent is critical.
---

### 🔹 AuditEval-SSL (Self-Supervised-Model based MOS Predictor)


1. **Install the required dependencies**  
   Download the Pretrained CLAP, AuditEval-ssl regression heads, and then install the required dependencies:
    ```bash
    pip install -r requirements_ssl.txt
    ```

2. **Run Evaluation**  
   In `AuditEval-ssl/pred.py`, specify the following fields:
   - Original audio path: `ori_path`
   - Edited audio path: `tar_path`
   - Original description: `ori_text`
   - Target (editing) description: `tar_text`
   Then execute the script below to obtain three scores—**Quality**, **Relevance**, and **Faithfulness**:
   ```bash
   bash AuditEval-ssl/pred.sh
   ```
3. **Train the Model**  
   If you need to train or fine-tune the MOS-predictor, you can use the following script:
   ```bash
   bash AuditEval-ssl/train.sh
   ```
   AuditEval-SSL is built upon a pretrained self-supervised learning (SSL) audio backbone (Clap) and predicts MOS-style scores directly from audio and text inputs. It excels in evaluating **Quality** and is relatively lightweight, making it an efficient choice for audio editing evaluation.
